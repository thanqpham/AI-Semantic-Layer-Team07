# `components/landing/` — Landing page

Mỗi file là một section của trang `/` (ghép trong `app/page.tsx`).

| File | Section |
| --- | --- |
| `navigation-section.tsx` | Thanh điều hướng đầu trang, chuyển ngôn ngữ, nút đăng nhập/dùng thử. |
| `hero-section.tsx` | Phần mở đầu: thông điệp chính và lời kêu gọi hành động. |
| `how-it-works-section.tsx` | Quy trình các bước từ kết nối dữ liệu đến sử dụng. |
| `bento-features-section.tsx` | Lưới tính năng chính (bento). |
| `metrics-section.tsx` | Số liệu/giá trị nổi bật. |
| `integrations-section.tsx` | Nguồn dữ liệu và tích hợp hỗ trợ. |
| `infrastructure-section.tsx` | Kiến trúc và hạ tầng. |
| `security-section.tsx` | Cam kết bảo mật (chỉ đọc, mã hóa Fernet, guardrail). |
| `developers-section.tsx` | Dành cho nhà phát triển (API, export). |
| `testimonials-section.tsx` | Trích dẫn/đánh giá. |
| `pricing-section.tsx` | Gói sử dụng. |
| `cta-section.tsx` | Lời kêu gọi cuối trang. |
| `footer-section.tsx` | Chân trang. |
| `animated-sphere.tsx`, `animated-tetrahedron.tsx`, `animated-wave.tsx` | Hình khối 3D/sóng động làm nền các section. |

> Nội dung landing mang tính giới thiệu; thông tin kỹ thuật chính xác nằm trong tài liệu ở thư mục gốc.
